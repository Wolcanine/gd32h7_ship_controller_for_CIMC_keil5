操作说明 — 水面垃圾收集船主控系统
项目: 水面垃圾收集船
MCU:  GD32H759IMK6
日期: 2026-07-01


================================================================================
一、开机
================================================================================

  1. 确认接线板各模块连接正确（见《接线板引脚表》）
  2. 确认 TOF200F 激光模块的 PA2/PD6 RS485 跳线帽已拔掉
  3. 给系统上电（12V 电池 -> 稳压模块 -> 核心板 + 驱动板 + 舵机）
  4. 打开 PS2 手柄电源（装电池，按 ANALOG 键开机）
  5. 串口助手连接 CH340 调试口（UART4, 9600bps）
  6. 观察启动信息：

     [PS2] OK
     [MPU6050] OK
     [TOF] OK
     [Motor] OK
     [ShipCtrl] OK
     [AutoNav] OK (manual)
     [ServoArm] OK
     [Stepper] OK
     [SW UART] CH1+CH2 9600bps OK
     [TIMER3] 50Hz started
     ===== System Ready =====

  7. 系统启动后默认进入手动模式（PS2 绿灯亮 = 模拟模式）


================================================================================
二、模式切换
================================================================================

  PS2 手柄有两个指示灯：

  红色 LED — 连接状态
      闪烁 = 手柄未连接（正在搜索接收器）
      常亮 = 手柄已连接

  绿色 LED — 模式指示（按 ANALOG 键切换）
      亮   = 模拟模式 (ANALOG)  = 手动操控
      灭   = 数字模式 (DIGITAL) = 自动航行

  模式对照:
  * 绿灯亮 (模拟/手动) —— MANUAL
      - 摇杆控制油门/转向
      - 机械臂全手动操作
      - SELECT+L1/L2 控制传送带

  * 绿灯灭 (数字/自动) —— AUTO
      - 激光避障自动驾驶
      - 机械臂手动遥控禁用
      - L1/L2 直接控制传送带

  模式切换时串口会打印:
    ===== SWITCH TO AUTO MODE (laser avoidance) =====
    ===== SWITCH TO MANUAL MODE (PS2 control) =====


================================================================================
三、手动模式操作
================================================================================

  3.1 航行控制 —— 左摇杆
  ------------------------------------------------------------------
  左摇杆上推              前进 / 加速
  左摇杆下拉              倒车 / 减速
  左摇杆左推              向左转向（差速）
  左摇杆右推              向右转向（差速）
  摇杆回中                滑行（电机断电）

  注: 油门带 PID 偏航稳定——左右转向由陀螺仪闭环控制，抗风浪干扰。

  3.2 机械臂控制 —— 各按钮
  ------------------------------------------------------------------
  按键         关节         说明
  ---------------------------------------------------------------
  LEFT/RIGHT   CH0 底座     左右旋转底座 (0~270度)
  UP/DOWN      CH1 大臂     大臂抬起/放下 (0~180度)
  SQUARE/CIRCLE CH2 小臂    小臂伸展/回收 (SQUARE=回收, CIRCLE=伸展)
  TRIANGLE/CROSS CH3 腕俯仰 手腕俯仰 (TRIANGLE=抬起, CROSS=下压)
  L1/L2        CH4 腕旋转   手腕旋转
  R1/R2        CH5 夹爪     夹爪开合 (R1=收紧, R2=张开, 限位51~141度)

  注: 各关节有安全限位。按键速度默认 5度/秒。

  3.3 传送带控制 —— SELECT 组合键
  ------------------------------------------------------------------
  按住 SELECT + L1        传送带正转（收垃圾）
  按住 SELECT + L2        传送带反转（释放垃圾）
  松开 SELECT             传送带停止

  注意: SELECT 不按时 L1/L2 控制腕旋转(CH4)，两者互不干扰。

  3.4 预设动作
  ------------------------------------------------------------------
  SELECT (短按)            机械臂回 PARK (收船位置)
  START                    捕获当前姿态到串口 (示教用)
  R3 (按下摇杆)            一键启动6阶段自动采集序列

  R3 采集序列 (6阶段自动执行):
    1) 移其他关节 (底座/小臂/腕/夹爪 到达抓取预备位)
    2) 大臂下压到位
    3) 闭合夹爪 (收集垃圾)
    4) 大臂先抬起 (返回)
    5) 其余关节归 PARK
    6) 张开夹爪 (投放垃圾)


================================================================================
四、自动模式操作
================================================================================

  4.1 自动驾驶说明
  ------------------------------------------------------------------
  进入自动模式后，船会自主执行激光避障航行：
    1. 直行前进 (油门 80%)
    2. 激光检测到前方 200cm 内有障碍 -> 转向 45度 避障
    3. 转向方向自动交替（左->右->左->右），避免原地打转
    4. 确认前方安全 -> 恢复直行
    5. 直行时传送带自动开启正转收垃圾
    6. 转向时传送带自动停止

  4.2 PS2 超驰控制（自动模式下仍可用的按键）
  ------------------------------------------------------------------
  ANALOG 键               切回手动模式
  CROSS (x) 按住          紧急停止 (电机置零)
  L1                      传送带正转 (超驰自动逻辑)
  L2                      传送带反转 (超驰自动逻辑)

  注: 自动模式下机械臂手动遥控被禁用。如需操作机械臂，先切回手动模式。


================================================================================
五、串口指令 (UART4, 9600bps)
================================================================================

  5.1 机械臂角度指令
  ------------------------------------------------------------------
  格式: { a, b, c, d, e, f }
  示例: { 128, 88, 97, 27, 98, 141 }
  说明: 6个数字对应 CH0~CH5 的目标角度，花括号和逗号/空格分隔。
        收到后机械臂以缓冲插值平滑移动到目标位置。

  5.2 调试信息（每秒自动上报）
  ------------------------------------------------------------------
  手动模式: PS2油门/转向、陀螺仪XYZ、加速度XYZ、激光距离
  自动模式: 状态(FWD/TURN)、油门、转向、激光距离、偏航角
  通用信息: 6路舵机角度+脉宽、GPS定位、步进电机步数


================================================================================
六、指示灯与告警
================================================================================

  6.1 手柄指示灯
  ------------------------------------------------------------------
  红色 LED 闪烁           手柄未连接（正在搜索接收器）
  红色 LED 常亮           手柄已连接
  绿色 LED 亮             模拟模式 = 手动操控
  绿色 LED 灭             数字模式 = 自动航行
  GPS 模块 LED 闪烁       已定位
  GPS 模块 LED 常亮/灭    未定位（冷启动需 30秒~数分钟）

  6.2 故障告警 (串口输出)
  ------------------------------------------------------------------
  *** EMERGENCY STOP: loop timeout! ***
    含义: 主循环超时 500ms，紧急停车

  *** PS2 DISCONNECTED -- motors stopped ***
    含义: PS2 手柄断开，电机自动停止（每5秒告警一次）

  [MPU6050] FAILED, continuing without gyro
    含义: 陀螺仪通信失败，PID 自动旁通（手动模式仍可控制电机）

  [Laser CRC ERR] count=N
    含义: 激光 CRC 校验错误，计数递增

  [Laser PARTIAL DROP] N bytes timed out
    含义: 激光帧超时，不完整帧被丢弃

  NAV: obstacle XXcm, turn LEFT/RIGHT
    含义: 自动模式检测到障碍，开始转向避障

  NAV: clear (XXcm), resume forward
    含义: 障碍已避开，恢复直行


================================================================================
七、安全注意事项
================================================================================

  7.1 上电顺序
  ------------------------------------------------------------------
  先给驱动板和舵机上电，再给核心板上电，避免舵机上电抖动。

  7.2 PS2 断连保护
  ------------------------------------------------------------------
  PS2 手柄断连时所有电机立即停止，机械臂保持当前位置。
  重新连接后自动恢复手动模式控制。

  注意: 自动模式下 PS2 断连 -> 船会继续自动驾驶！
  如需紧急停止，重新连接 PS2 后按 ANALOG 切回手动（电机会先置零再切换）。

  7.3 紧急停止
  ------------------------------------------------------------------
  手动模式: 摇杆回中 = 滑行（电机断电但船靠惯性继续移动）
  自动模式: 按 CROSS (x) = 电机置零
  极端情况: 拔掉 PS2 电池 -> 电机自动停止

  7.4 机械臂操作
  ------------------------------------------------------------------
  - 机械臂运动时注意船体平衡，避免大幅度动作导致侧翻
  - 夹爪限位 51度~141度，超出范围自动钳位
  - 腕旋转(CH4)和传送带共用 L1/L2，手动模式下需用 SELECT 组合键区分

  7.5 水面作业
  ------------------------------------------------------------------
  - 自动模式依赖激光测距，确保 TOF200F 镜头清洁无水雾
  - GPS 定位需在开阔水面，首次定位可能需数分钟
  - 强风浪环境下 PID 稳定有限，建议手动模式应对极端天气

  7.6 电池
  ------------------------------------------------------------------
  - 注意电池电量，低压可能导致舵机无力、电机失速
  - 建议作业时间不超过电池容量 80%
